ScreenVision AI

ScreenVision AI is an advanced medical imaging analysis tool with clinical triaging and urgency classification. It uses deep learning models to analyze various medical images including brain MRIs, skin lesions, chest X-rays, and eye fundus images. The software provides explainable AI visualizations, clinical question workflows, and generates detailed PDF reports with color-coded urgency assessments.

Learn More

Draft

Draft is a lightweight, Java-based text editor designed for simplicity and efficiency. Inspired by the functionality of Emacs, it provides a clean and intuitive interface for editing text files, with additional features like a built-in terminal for advanced users. It is ideal for writers and anyone who needs a fast and customizable text editing tool.

Learn More

Tabard

Tabard is a Chrome extension that enhances tab management by offering features like automatic grouping by domain, advanced search, session saving, and theme customization. It's designed to help users, including developers and casual browsers, maintain an organized and efficient browsing experience.

Learn More

Eventor

Eventor is a Chrome extension that helps you manage and organize browser events, improving your browsing workflow and productivity with smart event tracking and management features.

Get ScreenVision AI

ScreenVision AI Screenshots

Source

System Requirements

  • Operating System: Windows 10/11, macOS 10.15+, or Linux (Ubuntu 18.04+)
  • Python: Python 3.8 or later
  • RAM: 8 GB minimum (16 GB recommended for large images)
  • Storage: 2 GB of free disk space for models and dependencies
  • GPU: NVIDIA GPU with 4GB+ VRAM recommended (optional for acceleration)
  • Display: Minimum 1280x768 resolution
  • Dependencies: TensorFlow, OpenCV, Pillow, OpenAI API key

Key Features

  • Multi-modal medical image analysis (X-Ray, MRI, etc.)
  • Explainable AI with Grad-CAM++ heatmap visualizations
  • Clinical triaging workflow with patient assessment questions
  • Color-coded urgency classification (Routine to Emergency)
  • Comprehensive PDF report generation
  • Support for multiple deep learning models
